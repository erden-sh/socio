## Create and edit

Open a [Space](/docs/spaces), choose **New page** and give the document a useful title. The visual editor supports headings, emphasis, lists, checklists and tables. Type `/` to choose an available block. You can write directly without a model connection.

Pages autosave after you pause editing. The save status tells you whether the server received the changes. Use Cmd/Ctrl+S to save immediately, and wait for confirmation before closing a page or asking a socio to revise it. A document with syntax the visual editor cannot preserve stays in Markdown source mode; use that mode to keep its original content intact.

## Work with a socio

Open the page conversation and choose a specialist authorized for the Space. It receives the current saved document, not an unsaved local draft. Ask for a specific change and review what it proposes. A socio's permission to work in a Space does not mean every suggested edit is correct.

To save a post, video or article you found, start a message with `/unfurl` and its link: the page gets its full text and a static [link card](/docs/link-cards). Save-to-page in an ordinary chat creates a document from stored conversation text. Review that text before placing it in a shared Space. The page's source-conversation reference does not grant other readers access to your private conversation.

## Organize a document

Use the page menu to create a subpage, change its location within the Space or choose **Move to…** for another Space. Moving carries its active subpages and keeps the page's identity, history and conversations. Old links can locate it at its new address. Unsaved changes must save first. If the page contains a dataset view, verify the dataset is shared with the destination Space.

## When saving fails

A failed save is not a saved revision. Keep the tab and your draft while you investigate the error. Revision checks stop an older draft from silently overwriting a newer server version. On a conflict, compare or recover your local draft and resolve it deliberately; automatic retries stop after a failure until you act.

Avoid making a second copy just to dismiss a conflict: that can hide which document is current. Ask for help with the page title, time and reported error, without pasting sensitive content into a public issue. See [page conversations](/docs/page-conversations) for working beside the editor.
